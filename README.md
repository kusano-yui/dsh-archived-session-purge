# 归档会话彻底删除

在 Harness Web UI 中增加 **设置 → 归档会话** 页面。该页面按工作区分组列出所有已归档会话，可永久删除单个会话，或一次删除某个工作区中的全部归档会话。

与“取消归档”不同，删除会从当前配置中真正移除会话：

- 完整的 JSONL 会话目录，包括历史格式版本；
- 持久化的投影缓存记录（缓存文件作为兜底也会清理）；
- 归档标记与置顶状态；
- 会话在所属工作区记录中的归属位置。

只有已归档会话可以删除。仍有运行中状态的会话会被拒绝；如果日志删除失败，归档标记会保持不变，方便稍后重试。只有本地所有者（owner）身份可以调用删除端点。当前版本支持 JSONL 会话持久化后端；其他后端会被明确拒绝，不会做部分删除。

附件存放在共享的内容寻址存储中，可能被其他会话引用，因此本插件有意不删除附件。

## 安装

1. 克隆本仓库。
2. 在 Harness 插件管理器中，将 `archived-session-purge` 目录作为 bundle 安装。
3. 打开 **设置 → 归档会话**。

客户端 HMR 传输会自动加载该页面，无需重启宿主。

## 目录结构

- `index.js`：宿主端删除端点、会话日志与缓存清理逻辑；
- `client.js`：设置页界面、确认框与请求调用；
- `locale/`：插件管理器显示用的中英文标题与描述；
- `cordis.patch.yml`：bundle 的插件插入声明；
- `icon.svg`：插件图标；
- `test/`：宿主删除、客户端请求与组件渲染测试。

仓库只包含插件源码，不包含 DSH 配置、会话日志、附件或凭据。

## 测试

```bash
npm test
```

也可以单独运行：

```bash
node test/purge.test.mjs
node test/client.test.mjs
node test/render.test.mjs
```

宿主测试使用临时会话目录并模拟工作区注册表，不会触碰真实会话。
